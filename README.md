# 报个价

**工业采购询价与供应商报价平台。** 采购员发布需求，找到能做这项工作的工厂。供应商围绕同一份要求看图、提问和报价。采购团队可以把几家工厂的价格、交期和付款条件放在一起比较，并留下联系和选用记录。

**源码须先申请，禁止商用。** 本仓库公开项目介绍、发展计划和申请入口。维护者审核通过后，申请人才能通过获邀的 GitHub 账号拉取私有仓库中的源码。[申请源码](ACCESS.md) · [使用条款](LICENSE.md) · [发展方向](ROADMAP.md)

## 谁会用到它

| 使用者 | 日常遇到的问题 | 在报个价里怎么处理 |
| --- | --- | --- |
| 采购员、采购负责人 | 要求发到了不同的群，后来改过哪些内容、哪些厂回了价，很难对齐 | 在一条需求下维护说明、附件、截止条件和报价。直接邀请合适的工厂。记录跟谁联系过、最终如何选择 |
| 技术、工程同事 | 工厂需要确认图纸或工艺，工程师需要原问题和上下文 | 采购方给同事分配这条需求的问答权限。工程师可以在原问题下回复，涉及价格的资料另行授权 |
| 工厂业务员、报价员 | 收到询价后要先判断能否承接，再问细节、核成本。同一企业还可能有多人跟进 | 按供应能力找商机，收藏或转给同事接手，先存报价草稿，再代表企业提交正式报价 |
| 企业管理员、平台运营 | 同一人可能属于多家企业，目录里也可能有尚未入驻的工厂 | 企业管理员审核员工加入申请并分配权限。平台运营处理企业认证、企业认领、需求审核、举报和下架 |

## 一笔询价怎么走

以下用一笔虚构的“铝合金支架机加工”询价说明流程。

1. **采购员写需求。** 写明数量、工艺和交付要求，上传规格说明与图纸，分别设置附件的保密级别。内容没准备齐时先存草稿，准备好再提交审核。
2. **让能做的工厂看到。** 审核通过后，平台按需求类别和供应能力匹配。采购员也可以在供应商目录里找到具备报价资格的工厂，选中这条开放需求并点“邀请报价”。
3. **把影响报价的问题问清楚。** 一家工厂发现图纸上的表面处理要求不明确，可以在需求里私下提问，也可以追问或补图。采购方技术同事回复后，由提问方确认是否解决。工厂标记为影响报价的关键问题解决后，才能正式提交自己的报价。
4. **按同一口径比价。** 工厂填金额、交付周期、税费、运费和付款安排，确认后提交。另一家工厂可能总价较低但运费另计，采购员能把两家的条件并排看。有报价查看权限的人可以跟进联系人，再记录选用了哪家，或暂未选定。

截止时间到了，或报价名额已满，本轮停止收取新报价。采购团队可以继续查看已有记录。选择供应商之后，合同、付款和交货由双方另行办理。

## 目前能做什么

| 功能 | 当前行为 |
| --- | --- |
| 企业账号与成员 | 支持短信或密码登录，小程序接入手机号快捷登录。一个账号关联多家企业时，登录后先选企业。员工可申请加入已有企业。需求维护、答疑、查看价格和提交报价分别受权限控制。 |
| 采购需求 | 支持草稿、提交审核、按审核意见补充后重新提交、开放后补充说明、调整截止条件和提前结束。已发布需求可以举报，平台可以查处并下架。 |
| 查找供应商 | 按企业名、地区、供应能力和认证状态筛选。没有供应商的分类会隐藏。卡片区分“待认领”“未认证”“已认证”。公开建档的企业可申请认领。认领、认证、可否报价分别判断。 |
| 邀请与跟进 | 采购方可从供应商详情邀请有资格的企业参与指定需求，并查看邀请进度。遇到待认领企业，采购方可以请平台协助联系。供应商团队能收藏商机、转交同事、确认接手。 |
| 报价与资料 | 草稿留在供应商企业内。正式提交会锁定原报价，补充说明单独记录。需求附件支持保密分级、水印预览及按条件申请下载。审批、预览、下载都有相应记录。 |
| 消息 | 站内消息集中显示待办和业务进展。小程序设置中可申请五类一次性微信提醒，包括新商机、供应服务到期，以及本人发布需求的审核结果、新报价和供应商提问。提交采购需求后，用户可在同一个授权窗口选择所需的采购反馈。 |

## 项目结构

| 源码目录 | 用途 |
| --- | --- |
| `apps/enterprise` | 企业工作台。基于 Vue 和 uni-app，面向微信小程序、手机浏览器和桌面浏览器。 |
| `apps/admin` | 平台管理后台，使用 Vue 和 Vite 构建。 |
| `apps/api` | TypeScript 和 Fastify 服务。负责企业身份、业务权限、需求和报价流程、文件预览与通知任务，数据保存在 SQLite 中。 |
| `packages/shared` | 企业端、后台和 API 共用的数据类型与业务定义。 |

短信、微信登录和微信订阅需要部署者自行配置对应服务。平台的实际供应商名单、企业成员、采购记录、报价、附件及服务凭证均不随源码分发。

## 当前进度与下一步

采购和报价主流程已有接口与前端回归测试。手机快捷登录成功、微信订阅消息实际送达并打开对应业务、从微信相册和聊天文件上传后打开附件，仍需完成真机验收。浏览器已验证过大尺寸图片上传与水印预览。

近期优先把手机上的一笔采购走顺，再用真实询价找出哪些工艺经常无人应答、哪些条件容易让工厂反复追问，据此改善匹配和补充供应能力。项目的衡量标准是采购员能否收到可比较的报价、供应商能否判断并接手合适的询价。各阶段的检查方法见[发展方向](ROADMAP.md)。
